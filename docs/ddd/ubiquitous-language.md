\# 统一语言词汇表 Ubiquitous Language

项目：CampusOverflow



|术语|定义|

| ---- | ---- |

|用户|平台使用者，可以注册、登录，发布问题或者回答他人问题|

|管理员|特殊权限用户，可以删除违规提问和回答|

|问题(Question)|用户发布的学习相关提问，包含标题、正文，有发布时间、作者|

|回答(Answer)|针对某个问题写下的回复内容，绑定到对应问题，有作者|

|点赞|用户可以对回答进行点赞，统计回答获得的点赞数量|

|领域事件|系统里面发生的业务事件，例如问题发布、回答提交、回答被点赞|

|待办产品列表(ProductBacklog)|项目需要实现的全部功能需求清单|

|上下文(Bounded Context)|业务领域划分出来独立的业务模块边界|
